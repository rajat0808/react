# Rental Dresses — Lucknow

A premium web application for **Rental Dresses**, a luxury wardrobe rental and photoshoot service based in Lucknow.

## 🚀 Experience
The site features a multi-page editorial design focused on showcasing:
- **Maternity Shoots** (Gown, Saree, Temple, Ram-Sita themes)
- **Pre-Wedding Shoots**
- **Outfit Rentals** (Gowns, Lehengas, Blazers, Tuxedos)

## 🛠️ Tech Stack
- **Framework**: React + Vite
- **Styling**: Vanilla CSS (Premium Editorial Aesthetic)
- **Animations**: Framer Motion + CSS GPU Animations
- **Routing**: React Router DOM

## 📦 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd react
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

## 🌐 Deployment

To deploy the project to **GitHub Pages**:

1. Ensure you have a remote origin set:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   ```

2. Run the deployment script:
   ```bash
   npm run deploy
   ```

This will automatically build the project and push the `dist` folder to the `gh-pages` branch.
